# UI Core Module (`:core:ui`)

The `:core:ui` module contains the fundamental Jetpack Compose components, themes, and design tokens used to construct the visual identity of XCan.

## Architecture Role
- **Design Tokens**: Defines custom Colors (electric blue, neon accents), Typography, and Shapes.
- **XCanTheme**: The central Material 3 theme wrapper for the application.
- **Shared Components**: Reusable composables like buttons, cards, list items, dialogs, and custom-drawn canvases (e.g., dial gauges) that appear across multiple features.

## Dependencies
- None (independent visual layer)
